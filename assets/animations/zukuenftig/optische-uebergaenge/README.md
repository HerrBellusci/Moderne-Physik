# Material für ein mögliches Kapitel zu optischen Übergängen

Dieser Ordner ist nicht in das Workbook eingebunden und wird nicht veröffentlicht.

`nachleuchten.js` ist ein verworfener Entwurf aus dem Laser-Unterkapitel zur Besetzungsinversion. Vor einer späteren Verwendung muss die fachliche Modellierung neu geklärt werden. Insbesondere dürfen das Energieniveauschema des gesamten Atoms und die Darstellung einzelner Ladungsträger in einem Festkörper nicht ohne Einführung miteinander vermischt werden. Auch Elektronenfallen, Leuchtzentren und eine mögliche thermische Aktivierung benötigen dann eine eigenständige Erklärung.
